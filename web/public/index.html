Architecture

A model is a proposer, not the authority.

Reason

Connected models can draft, transform, summarize, plan, and generate candidate responses.

Verify

ClaimLock binds factual statements to evidence and withholds unsupported or contradictory claims.

Act with authority

Future agent actions stay behind permissions, approvals, tool policy, and an audit trail.

Platforms

One TruthCore. Multiple front ends.

ANDROID

Native Kotlin + Compose

Microphone input, Android speech recognition, text-to-speech, model settings, ClaimLock, and GitHub-built APKs.

WEB

Website + installable web app

Responsive public site, browser chat, optional voice controls, server-side provider proxy, and a port of TruthCore's deterministic truth gate.
