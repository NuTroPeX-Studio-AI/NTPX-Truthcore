# TruthCore v1.0 completion contract

TruthCore is considered source-complete when Android and Web can run the same core product behaviors: persistent memory, evidence retrieval, deterministic and semantic verification, model-backed conversation, agent planning, permissioned tools, approval/audit, and release CI.

External release blockers are not represented as completed work: production hosting/domain, live provider credentials, store signing secrets, and optional downloadable local model assets require operator-owned configuration.
